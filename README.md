# ✈️ Airline & Flight Data Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing airline operations, passenger travel behavior, airport traffic, ticket sales, and airline revenue using SQL.

The goal of this project is to solve real-world business problems in the airline industry through data analysis and SQL querying techniques.

---

## 🗂 Database Schema

The database consists of the following tables:

- Passengers
- Tickets
- Flights
- Airlines
- Airports
